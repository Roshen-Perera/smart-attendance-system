# AI Smart Attendance System

An AI-based attendance management system using deep learning facial recognition and exam eligibility prediction.

## Technologies

### Frontend

- React
- TypeScript
- Tailwind CSS

### Backend

- FastAPI
- Python

### AI

- OpenCV
- Deep Learning
- Face Embeddings

### Database

- PostgreSQL

## Project Structure

- frontend - React application
- backend - FastAPI API
- ml - Machine learning experiments
- docs - Technical documentation
